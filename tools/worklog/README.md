# 工作记录 · Work Log

把每天的活记下来，做完自动归档。两个页面：**日常工作**记待办，**常用数据汇总**存天天要开的飞书表格和文档。

打开 `index.html` 即可使用，纯本地、不联网、不用登录。

## 功能

### 日常工作

- 新建任务：要做什么 + 日期 + 说明（补充细节、进度、注意事项）+ 附件 + 飞书链接
- 列表里每条带日期、周几，当天标「今天」；日期早于今天还没做完的标**已过期**，顶部统计「N 项进行中 · M 项已过期」
- 点左边的圆圈即完成，任务归档到「已完成」，按**月份 → 日期**分组汇总，顶部显示「共完成 N 项任务」
- 已完成的任务可以「移回待办」，也可以随时编辑、删除

### 常用数据汇总

- 把常用的飞书表格、文档放进来：名称 + 链接地址 + 说明，一键直达
- 默认带一条示例（月度利润表），点编辑换成自己的链接即可

## 数据结构

数据存在本机 `localStorage`，两个键：

| 键 | 内容 |
| --- | --- |
| `worklog.tasks.v1` | 任务数组 |
| `worklog.links.v1` | 常用链接数组 |

任务对象：

```jsonc
{
  "id": "uuid",
  "title": "整理本月利润表数据",
  "date": "2026-10-22",        // YYYY-MM-DD
  "note": "核对收入与成本",     // 说明，可空
  "done": false,
  "createdAt": 1761096000000,
  "completedAt": null,          // 完成时间戳，未完成为 null
  "attachments": [{ "id": "uuid", "name": "原始数据.xlsx", "url": "" }],
  "feishuUrl": ""
}
```

## 使用注意

- **附件只记名字和链接，不存文件本体。** 页面上填的是「附件名称」和可选的「链接（可选）」两栏，文件本身要自己放到云盘 / 飞书里，再把地址贴上。这样整份数据才塞得进 `localStorage`。
- 数据只在这台机器的这个浏览器里（`localStorage`），换设备、换浏览器、清缓存都会丢。重要内容请及时同步到飞书。
- 首次打开自带两条示例任务（「整理本月利润表数据」「提交上周周报」），标了「示例，可删除」，删掉即可。

## 关于结尾那段 Dalek 同步脚本

`index.html` 末尾有一块 `<!-- dalek-worklog-sync:start -->` 的脚本，作用只有一个：把 `worklog.tasks.v1` 每 1.5 秒推给本机 `127.0.0.1:45873` 的 Dalek 桌面宠物主进程，让桌宠能显示今天的任务。

- 这段是**可选的**，和工具本身无关：Dalek 没开着、端口不通时就是静默失败，页面功能一点都不受影响。
- 从 GitHub Pages 打开时页面是 `http(s)://` 而不是 `file://`，脚本推过去的 `file` 字段为空，Dalek 会以 409 拒收并让脚本停止重试——所以线上版本不会去碰你本机的那份清单。
- 想彻底去掉，把 `<!-- dalek-worklog-sync:start -->` 到 `<!-- dalek-worklog-sync:end -->` 之间整块删掉即可。

## 技术

- 单文件 HTML，样式、脚本全部内联；React 应用打包后的产物，无外部依赖、无 CDN，双击就能跑
- 单文件约 540 KB（React + Radix UI + Framer Motion 全打包进去），这是为了「一个文件带走」付的体积代价
- 需要较新的浏览器（Chrome / Edge 90+）
