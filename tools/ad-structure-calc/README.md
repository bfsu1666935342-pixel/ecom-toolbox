# 广告结构反推测算 · Ad Structure Estimator

一个单文件、零依赖的亚马逊广告结构反推测算器：输入售价、毛利与广告结构（层级 → 广告活动 → 关键词），反推每天能花多少钱、能出多少单、以及是否还留有利润空间。

打开 `index.html` 即可使用，不需要安装、不需要联网、不依赖任何框架。

> 这是 [跨境电商工具箱](../..) 里的第一个工具（`tools/ad-structure-calc/`）。

## 功能

- **三层结构**：层级 → 广告活动 → 关键词。层级可折叠，活动可展开查看关键词。
- **层级一眼分清**：每个层级左侧一条彩色竖条（7 色轮换），行内加粗；活动行缩进对齐到层级下方。
- **层级汇总行**：直接在该层显示「X 个活动 / Y 个词」、汇总点击率、汇总 CPC、汇总转化率、以及状态（几个活动受搜索量限制 / 全通）。
- **批量录入关键词**：一个关键词一行粘进一个框里，月搜索量单独一列按行对应，自动对齐。
- **活动搜索量自动求和**：活动的月搜索量 = 该活动所有关键词搜索量之和（短语 / 广泛按同词的精准搜索量计，不折算）。
- **点击上限双约束**：可拿到的点击 = 活动搜索量 ÷ 30 × 点击率；预算能买的点击 = 日预算 ÷ CPC；两者取小，超出预算标「搜索量受限」。
- **利润基准**：售价、单件毛利、目标日销（总单口径）、ACoAS 目标。
- **新品 / 老品双模式**：新品默认「全部靠广告」，自然单记 0；切到老品优化后可填「自然订单占比」，自然单 = 目标日销 × 占比，合计单 = 广告单 + 自然单，平本花费与 ACoAS 都按合计单计算。
- **三段式汇总**：① 结构产出（实花、点击、广告单、自然单、合计单、综合 CPA）② 平本基准（平本 ACoAS、平本花费、单件毛利、目标日销）③ 对比结论（实花 / 平本进度条 + 差额、差额 %、实际 ACoAS、实际利润率），并给出结论判定。
- **层级汇总行**：直接在该层显示「X 个活动 / Y 个词」、汇总点击率、汇总 CPC、汇总转化率、以及状态（几个活动受搜索量限制 / 全通）。
- **案例管理**：改动自动存本机 `localStorage`，重要组合可另存为案例随时载入。
- **案例导出 / 导入**：一键导出 `.json`（含全部案例 + 当前表格），换电脑或换浏览器时导入还原；同名案例自动覆盖，其余保留，导入时可选是否同时载入文件里的表格。也可当定期备份。
- 深色 UI、响应式布局，手机也能用。

## 使用

直接双击 `index.html`，或用任意静态服务器托管：

```bash
python -m http.server 8000
```

然后用浏览器打开 <http://localhost:8000>。

## 主要算式

| 指标 | 算法 |
| --- | --- |
| 活动月搜索量 | Σ 该活动下所有关键词的月搜索量 |
| 可拿到的点击 / 天 | 活动月搜索量 ÷ 30 × 点击率 |
| 预算能买的点击 / 天 | 日预算 ÷ CPC |
| 实际点击 / 天 | min(可拿到, 预算能买) |
| 曝光 / 天 | 点击 ÷ （点击率 ÷ 100） |
| 层级汇总点击率 | Σ 该层点击 ÷ Σ 该层曝光（加权，不做各活动简单平均）|
| 层级汇总 CPC | Σ 该层花费 ÷ Σ 该层点击 |
| 层级汇总转化率 | Σ 该层单量 ÷ Σ 该层点击 |
| 单 / 天 | 点击 / 天 × 转化率 |
| CPA | 花费 ÷ 单量 |
| 自然单 / 天（老品） | 目标日销 × 自然订单占比 |
| 合计单 / 天 | 广告单 + 自然单 |
| 平本 ACoAS | 单件毛利 ÷ 售价 |
| 平本花费 / 天 | 单件毛利 × 合计单量 |
| 实际 ACoAS | 广告实花 ÷ （合计单量 × 售价）|

新品模式下自然占比强制为 0，合计单 = 广告单；老品模式下自然单只按目标日销 × 占比估算，**不随广告结构变化**（自然流量不被广告预算拉动，是这套模型的简化假设）。

结论判定：实际花费高于平本花费即亏损风险，低于则仍有放量余量。

> 单量为线性外推：未考虑加大投放后竞价被抬高、转化率下滑等二阶效应，只适合做结构层面的粗略体检。

## 技术说明

- 纯 HTML + CSS + 原生 JavaScript，无构建步骤、无第三方依赖。
- 数据只存在浏览器本地（`localStorage`），不上传到任何服务器；换浏览器或清除缓存会丢失，重要数据请「保存为案例」并定期「导出 JSON」备份。
- 单文件约 41 KB。
