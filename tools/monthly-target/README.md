# 月目标日均测算 · Monthly Target Planner

把旺季的**月目标**拆成「平时日均」和「活动日均」，回答两个问题：

- 这个月每天要卖多少，活动期（黑五 / 圣诞）每天要冲多少？
- 按现在的日均，离目标还差多少？

打开 `index.html` 即可使用，纯本地、不联网。

## 输入

| 参数 | 说明 |
| --- | --- |
| 活动倍数 | 活动期的日销是平时的几倍（默认 5） |
| 11 月天数 / 12 月天数 | 各月自然天数 |
| 黑五起 / 止 | 11 月里的活动区间（默认 19–30 日，共 12 天） |
| 圣诞活动天数 | 12 月里的活动天数（默认 15 天） |

每个产品填三项：**11 月目标**、**12 月目标**、**现日均**。

## 计算逻辑

```
平时日均 = 月目标 ÷ (平时天数 + 活动天数 × 倍数)
活动日均 = 平时日均 × 倍数
活动合计 = 活动日均 × 活动天数
12 月差距 = 12 月平时日均 − 现日均
```

页面顶部会实时显示本次的公式实例，例如：
`目标 ÷ (18 平时 + 12 活动 × 5) → 平时日均 = 目标 ÷ 78`

同时给出活动期占整月目标的比例，方便判断「这个月的量是不是压在一个活动周里」。

## 使用

- 产品名可以直接在表格里点开改（contenteditable）
- 「+ 加一个产品」「恢复默认」「导出 CSV」（带 BOM，Excel 打开不乱码）
- 输入不逐字重算：停手 0.6 秒、按回车或离开输入框才计算
- 数据存在本机 `localStorage`（键 `monthlyPromoCalc.v2`），换浏览器会丢，需要留档请导出 CSV

## 说明

- 默认案例里的产品名已做**脱敏处理**（产品 A～F），数字为示例量级，可直接改成自己的。
